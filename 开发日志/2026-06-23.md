### 🔧 四大 Bug 修复（第二轮）

#### 1. 语音输入功能不见了 ✅
**原因**: 流程精简时 Step5Mood（含语音录制 UI）被移除，未迁移到 Step2Info
**修复**:
- Step2Info 新增完整的语音录制功能（MediaRecorder API）
- 三种 UI 状态：开始录音 → 录音中（波浪动画 + 计时）→ 已完成（播放 + 重录）
- 录音保存为 base64 data URL（audio/webm, opus 编码）
- `INewRecordDraft` / `ITeaRecord` 新增 `audioDataUrl` 字段
- ReceiptModal 接入真实音频播放（替代模拟）
- 样式迁移自 Step5Mood.css，融入 Step2Info.css

#### 2. 奶茶记录依旧无法保存 ✅
**根因分析**:
- `URL.createObjectURL(blob)` 生成临时 blob URL，页面导航后立即失效
- 原始照片 base64 3-7MB + 抠图 PNG 更大 → 超出 localStorage ~5MB 配额 → `setItem` 静默失败

**修复**:
- 新建 [src/utils/imageUtils.ts](src/utils/imageUtils.ts)
  - `compressImage()` — Canvas 缩放到 800px 宽 + JPEG 0.7 质量 → ~50-100KB
  - `blobUrlToDataUrl()` — blob URL → 永久 data URL
  - `processCutoutResult()` — blob→data→compress 全流程
- Step1Photo `runCutout()` 同步压缩原图 + 抠图结果
- `saveRecord()` / `saveAll()` 返回 boolean → Step2Info 根据返回值显示成功/失败 toast
- 失败时提示 "存储空间不足，请尝试压缩照片后重试"

#### 3. 不能自动识别图片时间 ✅
**修复**:
- `readExifDate()` 双层策略：自定义 JPEG 解析器（快）→ 失败回退 `exif-js` 库（覆盖更多边缘情况）
- `exif-js` 通过动态 `import()` 加载，不增加初始包体积
- 日期格式正则验证（`/^\d{4}-\d{2}-\d{2}$/`）

#### 4. 无法抠图 ✅
**修复**:
- Step1Photo 挂载时预加载 `@imgly/background-removal` 模型（WASM ~24MB）
- UI 显示"正在准备抠图引擎..."→ 模型就绪后才提示拍照
- 抠图失败自动降级为压缩原图
